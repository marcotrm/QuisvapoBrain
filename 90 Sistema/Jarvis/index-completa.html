Connessione al vault (plugin: Local REST API)

ℹ️ Se avvii Jarvis con avvia-jarvis.bat la connessione è automatica (il server legge la chiave dal plugin): questa pagina serve solo come ripiego se apri index.html direttamente.

  1. In Obsidian → Impostazioni → Local REST API: copia la API Key
  2. Consigliato: attiva "Enable Non-encrypted (HTTP) Server" (porta 27123) — evita problemi di certificato
  3. Se usi HTTPS (27124): apri prima https://127.0.0.1:27124 e accetta il certificato

La chiave resta solo nel tuo browser (localStorage), su questo PC.
